## 배운 개념

### 1. 빅오가 묻는 것

"원소 100만 개일 때 몇 번이냐" ❌
**"원소 수 n 에 대해 비용이 어떤 모양으로 커지냐"** ✅

### 2. 규칙 두 개

1. **숫자를 대입하지 않고 n 을 그대로 둔다.**
2. **상수는 버린다.** `n/2`, `2n`, `3n+5` → 모두 O(n). n 과 무관한 3번·50번·0번 → 모두 O(1).

### 3. 2배 판별법 (기계적으로 쓰기)

> **"n 을 2배로 늘리면 비용이 몇 배가 되나?"**

| 결과 | 빅오 | 예시 |
|---|---|---|
| 그대로 (1배) | **O(1)** | 배열 `get(i)`, ArrayList 맨 끝 삭제, HashMap 평균 get |
| 2배 | **O(n)** | 순회, 배열 복사, ArrayList `add(0,x)`, LinkedList `get(i)` |
| 4배 | **O(n²)** | 이중 for 문, +1 씩 늘리는 add 전체 |

(O(log n) 은 2배로 하면 비용이 "+1 단계" 정도만 늘어나는 것 — 이진 탐색, 레드-블랙 트리)

```
2n + 10 :  n=100 → 210,   n=200 → 410    ≈ 2배  → O(n)
50      :  n=100 → 50,    n=200 → 50     1배    → O(1)
n × n   :  n=100 → 1만,   n=200 → 4만    4배    → O(n²)
```

### 4. 복합 연산은 큰 쪽이 이긴다

`LinkedList.add(index, x)` = 찾기 O(n) + 연결 O(1) = **O(n)**

### 5. 분할 상환(amortized) O(1)

가끔 O(n) 비용이 터지더라도 전체 비용 / 연산 횟수가 n 과 무관한 상수면 **분할 상환 O(1)**. (예: ArrayList add — [[arraylist-internals]])

## 오답·헷갈린 점 (이번 세션 최다 반복 실수)

- **전**: `O(250,000)`, `25만번`, `99만9999` 처럼 **구체 숫자로 답함** → **후**: n 으로 일반화 후 상수 제거 → O(n).
- **전**: 이동 0번이면 `O(0)` → **후**: **O(1)**. O(1) 의 1 은 "1번" 이 아니라 "n 과 무관한 상수". O(0) 표기는 없다.
- **전**: `2n + 10` → `O(N*2)` → **후**: 상수 2 와 +10 버림 → O(n).
- **전**: `n × n` → `O(N)` → **후**: 2배 판별 시 4배 → O(n²). (판별법 적용 후 정답)
- **전**: 고정 비용 50 → `O(N)` → **후**: n 을 바꿔도 50 그대로 → O(1).
- **전**: 분할 상환 1회당 2~3 을 `O(n²)`, `분할상환 (O)` → **후**: **분할 상환 O(1)** — 괄호 안 숫자까지.
- 판별법을 익힌 뒤 LinkedList 찾기 O(n) / 연결 O(1) / 전체 O(n), HashMap get O(1), 최악 O(n) 은 **힌트 없이 정답**.

## Q&A

- **Q. n/2 번 이동이면?** A. O(n). n 이 2배면 n/2 도 2배.
- **Q. 이동 0번이면?** A. O(1).
- **Q. 1칸씩 늘리는 ArrayList 의 add 10,000번 총 복사량과 복잡도?** A. ≈ 5,000만, O(n²).
