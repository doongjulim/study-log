## 배운 개념

### 1. 누가, 언제 id 를 만드나

| | 누가 | 언제 |
|---|---|---|
| `IDENTITY` | DB (identity / auto_increment 컬럼) | **INSERT 를 실행해야** 생김 |
| `SEQUENCE` | DB (시퀀스 객체) | `persist` 때 **INSERT 전에** `nextval` 로 받아 옴 |

```
-- SEQUENCE
new Post(...)          → id = null (DB 와 무관)
em.persist(post)       → select nextval('post_seq')    ← 번호를 먼저 받아 옴
                       → post.id = 1 → 1차 캐시 저장 (INSERT 는 아직)
커밋 직전 플러시        → insert into post (id, ...) values (1, ...)
```

- 시작값·증가값은 엔티티가 아니라 **DB 시퀀스 객체의 속성**.

### 2. IDENTITY 에서 persist 가 하는 일

```java
@Transactional
public void write() {
    Post post = new Post("제목", ...);
    em.persist(post);                       // ← 여기서 INSERT 즉시 실행
    System.out.println(post.getId());       // 값이 찍힌다 (null 아님)
}
```

```
1차 캐시는 id 를 키로 엔티티를 저장한다
  → IDENTITY 는 persist 순간 id 를 모른다 → 키가 없어 캐시에 넣을 수 없다
  → Hibernate 는 persist 순간 INSERT 를 즉시 실행
  → JDBC getGeneratedKeys() 로 DB 가 만든 id 를 받아 엔티티에 세팅
  → 1차 캐시에 저장
```

> **IDENTITY 전략에서는 그 엔티티의 INSERT 에 쓰기 지연이 동작하지 않는다.**

### 3. 즉시 INSERT ≠ 커밋

- INSERT 가 **나갔다**는 건 플러시된 것이지 커밋된 게 아니다 (10/12 플러시 vs 커밋).
- `persist` 뒤 예외 → 이 INSERT 도 롤백되어 DB 에 남지 않는다.
- 하지만 **id 번호는 소비된 채** 돌아오지 않는다 → IDENTITY 테이블의 id 에 구멍.
- SEQUENCE 도 allocationSize 로 받아 둔 번호를 재시작 때 버려 구멍이 생긴다 → **어느 전략도 연속 id 를 보장하지 않는다**.

### 4. study-board

- 엔티티 **전부** `@GeneratedValue(strategy = GenerationType.IDENTITY)`, DB 는 `bigint generated by default as identity`.
- 글 하나 저장 = INSERT 1~2건 → 즉시 나가든 커밋 때 나가든 비용 차이 거의 없음.

## 오답·헷갈린 점

- **전**: SEQUENCE 는 "엔티티 생성 시에 시작값과 증가값을 지정해서 엔티티 생성 시에 만들어진다" → **후**: `new` 는 DB 와 무관. **`persist` 시점**에 DB 시퀀스 객체에서 `nextval` 로 받아 온다. 시작값·증가값은 **시퀀스 객체의 속성**.
- **전**: 단점 = "DB 에 저장돼야 id 가 생기는 구조라 지연쓰기 불가" → **후**: 중간 고리 **"1차 캐시의 키가 id"** 가 빠짐. 이 고리가 없으면 "id 가 늦게 생기는 게 쓰기 지연이랑 무슨 상관?"에 답 못 함.
- ✅ persist 시 INSERT 즉시 실행, getId() 값 있음, 쓰기 지연 불가는 스스로 정확히 추론.

## Q&A

- **Q. IDENTITY / SEQUENCE 의 id 는 누가, 언제?** A. IDENTITY 는 DB 가 INSERT 시. SEQUENCE 는 DB 시퀀스 객체가 persist 때 INSERT 전에.
- **Q. 1차 캐시의 키는?** A. id.
- **Q. IDENTITY 에서 persist 순간 나가는 SQL?** A. INSERT.
- **Q. persist 직후 getId()?** A. 값이 있다.
- **Q. 무엇이 동작하지 않나?** A. 쓰기 지연.
