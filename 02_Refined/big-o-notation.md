# 빅오 표기법

## 개념 정의

빅오가 묻는 것은

- ❌ "원소가 100만 개일 때 **몇 번** 실행되나"
- ✅ "원소 수 **n 이 커질 때** 비용이 **어떤 모양**으로 커지나"

그래서 두 규칙이 따라 나온다.

1. **숫자를 대입하지 않는다.** 결과는 항상 n 의 식이다. `O(250,000)` 같은 표기는 없다.
2. **상수와 작은 항은 버린다.** `n/2`, `2n`, `3n + 5` 는 모두 같은 모양 → **O(n)**. n 과 무관한 0번·3번·50번 → 모두 **O(1)**.

## 작동 원리 — 2배 판별법

> **"n 을 2배로 늘리면 비용이 몇 배가 되나?"**

| 결과 | 빅오 | 예시 |
|---|---|---|
| 그대로 (1배) | **O(1)** | 배열 `get(i)`, ArrayList 맨 끝 삭제, HashMap 평균 get |
| +1 단계 정도 | **O(log n)** | 이진 탐색, 레드-블랙 트리 탐색 |
| 2배 | **O(n)** | 전체 순회, 배열 복사, ArrayList `add(0,x)`, LinkedList `get(i)` |
| 4배 | **O(n²)** | 이중 for 문, 루프 속 문자열 `+` 누적, +1 씩 늘리는 배열 |

```
2n + 10 :  n=100 → 210    n=200 → 410     ≈ 2배  → O(n)
n / 3   :  n=100 → 33     n=200 → 66        2배  → O(n)
50      :  n=100 → 50     n=200 → 50        1배  → O(1)
n × n   :  n=100 → 1만    n=200 → 4만       4배  → O(n²)
```

### 복합 연산 — 큰 쪽이 이긴다

`LinkedList.add(index, x)` = 찾기 O(n) + 연결 O(1) = **O(n)** ([[linkedlist-internals]]).
n 을 2배로 하면 찾기가 2배, 연결 4번은 그대로 → 전체 약 2배.

### 분할상환(amortized) O(1)

가끔 O(n) 이 터져도 **전체 비용 ÷ 연산 횟수** 가 n 과 무관한 상수면 분할상환 O(1) 이다.

| ArrayList add 10,000회 | 총 복사량 | add 1회당 | 표기 |
|---|---|---|---|
| +1 칸씩 확장 | ≈ 5,000만 | n 에 비례해 증가 | 전체 O(n²) |
| 1.5배씩 확장 | ≈ 2.8만 | 약 2~3 (n 이 1억이어도 동일) | **분할상환 O(1)** |

핵심은 **배수 확장** — 큰 복사 한 번 뒤에 복사 없는 연산이 그만큼 많이 따라와서 비용을 나눠 진다 (할부). ArrayList([[arraylist-internals]]), StringBuilder([[string-concatenation-cost]]), HashMap resize([[hashmap-internals]]) 모두 같은 전략.

## 트레이드오프 / 한계

- **빅오는 모양만 말한다.** 같은 O(n) 이라도 상수 차이(캐시 미스, 객체 생성)로 실측은 몇 배씩 다를 수 있다 — ArrayList vs LinkedList 순회가 그 예 ([[linkedlist-internals]]).
- **작은 n 에선 상수가 이긴다.** n=10 이면 O(n²) 알고리즘이 O(n log n) 보다 빠를 수도 있다.
- **평균과 최악을 구분해서 말해야 한다.** HashMap get 은 평균 O(1), 한 칸 몰림 시 최악 O(n) (트리화 시 O(log n)).
- **분할상환 O(1) ≠ 매번 O(1).** 확장이 터지는 그 한 번은 O(n) — 지연에 민감하면 초기 용량으로 확장 자체를 없앤다.

> [!WARNING]
> **오답 코너**
> - **"get(500_000) 은 O(250,000)" / "99만 9,999번"** — 빅오에 **숫자를 넣지 않는다.** n 으로 일반화하고 상수를 버리면 O(n).
> - **"이동이 0번이면 O(0)"** — **O(1).** 1 은 "1번"이 아니라 "**n 과 무관한 고정 비용**"이라는 표시다. O(0) 표기는 쓰지 않는다.
> - **"2n + 10 은 O(N*2)"** — 상수 2 와 +10 은 모양을 바꾸지 못한다 → **O(n)**.
> - **"n × n 은 O(N)"** — 2배 판별 시 **4배** → **O(n²)**.
> - **"고정 비용 50 은 O(N)"** — n 을 바꿔도 50 그대로 → **O(1)**.
> - **"분할상환으로 1회당 2~3 이면 O(n²)" / "분할상환 O"** — **분할상환 O(1)**. 괄호 안 숫자까지 말해야 의미가 있다.
