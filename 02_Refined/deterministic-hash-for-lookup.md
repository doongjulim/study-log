# 결정적 해시와 DB 조회

## 한 줄 정의

해시는 되돌릴 수 없으므로, 검증에 앞서 **"DB에서 그 행을 어떻게 찾느냐"**가 먼저 풀려야 한다. 조회 키가 비밀값 자신뿐이라면 해시가 **결정적(deterministic)** 이어야 한다.

## 두 패턴의 대비

### 패턴 A — 별도의 조회 키가 있다 (로그인)

```
클라이언트가 보낸 것: id = "alice", password = "hunter2"
```

```sql
SELECT * FROM users WHERE id = 'alice'
```

**비밀번호가 아니라 아이디로 찾는다.** 행을 특정한 뒤 저장된 해시를 꺼내 검증한다.

```java
BCrypt.matches("hunter2", 저장된해시)
```

BCrypt 해시 문자열은 `$2b$12$<salt><digest>` 형태로 **salt를 자기 안에 담고 있다.** 그래서 저장값에서 salt를 꺼내 같은 조건으로 재계산·비교할 수 있다. 비결정적이어도 문제가 없는 건 **비교 대상이 이미 한 행으로 좁혀져 있기 때문**이다.

> **찾기와 검증이 분리되어 있고, 검증 연산은 딱 1회다.**

### 패턴 B — 비밀값이 곧 조회 키다 (토큰 갱신)

```
클라이언트가 보낸 것: token = "a3f9c2...8e1b"   ← 이게 전부
```

아이디도, 사용자 식별자도 함께 오지 않는다. 서버가 가진 유일한 단서가 토큰 문자열이다.

```sql
SELECT * FROM refresh_tokens WHERE token_hash = ?
```

이 쿼리가 성립하려면 **같은 입력에 항상 같은 출력**이 나와야 한다.

## 알고리즘별 귀결

| | salt | 결정적? | `WHERE hash = ?` | 조회 비용 |
|---|---|---|---|---|
| **SHA-256** | 없음 | ✓ | 성립 | 유니크 인덱스 → **O(log n)** |
| **BCrypt** | 매번 랜덤 | ✗ | **성립 안 함** | 전체 스캔 + 행마다 BCrypt |

BCrypt로 저장하면 방금 받은 토큰을 해시해봐야 저장된 값과 절대 일치하지 않는다(salt가 다르므로). 유일한 방법은 **모든 행을 꺼내 하나씩 `matches()`를 돌리는 것**이다.

**10만 행 × 250ms(cost 12) ≈ 7시간.** 토큰 갱신 요청 한 건에.

## 왜 토큰은 salt가 없어도 되는가

salt의 목적은 두 가지다.

1. **레인보우 테이블 무력화** — 미리 계산해 둔 해시 테이블을 못 쓰게 한다
2. **동일 값 노출 방지** — 두 사용자가 같은 비밀번호를 쓸 때 해시가 같아지는 걸 막는다

`SecureRandom` 256비트 토큰은 **두 목적이 모두 자동 충족된다.** 레인보우 테이블을 만들 수 있는 크기가 아니고(10⁷⁷), 값이 이미 전역적으로 유일하다. salt가 하던 일을 엔트로피가 이미 하고 있으니, salt를 붙여 조회 가능성을 잃을 이유가 없다.

## 설계 원칙

> 저장할 비밀값이 **자기 자신으로 조회되어야 하는 값**이라면, 그 순간 비결정적 해시(BCrypt / Argon2 / scrypt)는 선택지에서 탈락한다. 알고리즘의 강도와 무관한, **구조적 제약**이다.

이 제약은 초대 코드처럼 저엔트로피 값에도 그대로 걸린다. 저엔트로피라서 BCrypt가 필요해 보여도, 코드만 받아 그룹을 찾아야 한다면 쓸 수 없다. 그때는 방어를 [[offline-vs-online-attack]] 쪽 축(레이트 리밋)으로 옮긴다.

> [!WARNING]
> **오답 코너**
>
> - **"BCrypt는 salt가 랜덤이라 검증 자체가 불가능하다"** — 아니다. salt가 해시 문자열 안에 들어 있어 검증은 된다. 불가능한 건 **검증이 아니라 조회**다. 이 둘을 구분하는 게 핵심이다.
> - **"로그인도 비밀번호로 행을 찾는다"** — 아이디로 찾는다. 비밀번호는 찾은 뒤 대조하는 값이지 조회 키가 아니다.
> - **"인덱스만 걸면 BCrypt도 빠르다"** — 인덱스는 결정적 값에만 걸린다. 매번 다른 값이 나오는 컬럼은 조회 조건이 될 수 없다.
